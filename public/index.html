03 / QUICK SETUP

Run it locally

  1. Install Node.js 20 or newer.
  2. Extract this website project and open the folder in VS Code or a terminal.
  3. Copy .env.example to .env and add your Gemini API key on the server only.
  4. Run npm start and open http://127.0.0.1:3000.
  5. To install the manager, extract its download and copy the inner PlaceholderGuard folder into your Unity project's Packages folder.

Read docs/PlaceholderGuard-0.2.0-README.txt for the manager's detailed installation and feature guide. Test the package in a disposable Unity project before using it in production.
